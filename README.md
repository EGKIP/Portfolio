# Emmanuel Kiprotich — Portfolio

Personal portfolio for Emmanuel Kiprotich, a software engineer and machine
learning researcher working across retrieval-augmented generation, federated
learning, deep reinforcement learning, computer vision, and production AI
systems.

## Development

```bash
npm install
npm run dev
```

Use `npm run build` for a production build and `npm run lint` for static checks.

The portfolio content is maintained in `src/data/site.ts`; reusable layout and
presentation components live under `src/components` and `src/sections`.
